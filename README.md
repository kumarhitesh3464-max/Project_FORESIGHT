# 📌 Project Overview

Retail businesses often struggle with:

- Stock-outs
- Overstock Inventory
- Poor Demand Forecasting
- High Inventory Holding Cost
- Inefficient Reorder Planning

Project FORESIGHT combines Machine Learning, Forecasting Models, Inventory Risk Scoring, and Business Intelligence dashboards to help retailers optimize inventory decisions and improve operational efficiency.

---

# 🎯 Business Objectives

- Forecast future product demand
- Reduce stock shortages
- Reduce excess inventory
- Improve inventory planning
- Detect inventory risks
- Support business decision-making through interactive dashboards

---

# 📂 Datasets

The project uses four retail datasets:

- sales_daily.csv
- sku_master.csv
- calendar.csv
- inventory_snapshots.csv

# 🧠 Machine Learning Models

Models evaluated:

- Baseline Forecast
- Random Forest
- XGBoost
- LightGBM
- Prophet
- ARIMA / SARIMA

Model performance was evaluated using:

- MAE
- RMSE
- MAPE
- R² Score

# 🚀 Installation

Clone the repository

```bash
git clone <repository-url>
```

Move into the project directory

```bash
cd Project_FORESIGHT
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run streamlit_app/app.py
```
